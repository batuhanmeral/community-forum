# Security Policy

## Supported versions

Only the `main` branch is supported. Fixes land on `main`; there are no maintained release branches.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub instead: open the repository's **Security** tab and click **Report a vulnerability** (private vulnerability reporting). Include:

- what is affected (endpoint, component, file or commit)
- steps to reproduce or a proof of concept
- the impact you expect

## What to expect

- A first response within 7 days.
- Updates as the report is triaged and fixed. If it is confirmed, the fix is released on `main` and a GitHub security advisory is published, crediting you unless you ask otherwise.
- Please keep the details private until the fix is released.
